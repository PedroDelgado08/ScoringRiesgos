PD

Probabilidad de que el cliente no pague. Modelo de clasificación entrenado con préstamos de Lending Club de 2007 a 2015.

EAD

Parte del importe que sigue pendiente cuando llega el impago. Modelo de regresión.

LGD

Parte de lo pendiente que no se recupera. Se usa la media histórica (0,869), porque ningún modelo la mejoraba.
